Crete App Flow & User Journey - Discord for DAOs
Login/Onboarding Flow
Initial Screen
3 main options:
Connect Wallet (primary button) - Full access
Browse as Guest (secondary) - View-only mode
Import from Discord (tertiary) - Migration flow
Connect Wallet Flow
Wallet Selection - Phantom, Solflare, Backpack (mobile), WalletConnect (others)
Wallet Connect - Standard Solana wallet connection
Profile Setup - Display name, avatar (optional, defaults to wallet-based)
Permissions - Notifications, microphone, camera
Welcome Screen - Quick tutorial (3 screens max)
Browse as Guest Flow
Public Communities - Can view channels, cannot participate
Upgrade Prompt - Connect wallet to join (persistent banner)
Limited Features - Read-only, no chat/voice/voting
Discord Import Flow
Discord OAuth - "Continue with Discord"
Server Detection - Auto-detect servers user is in
Role Mapping - Match Discord roles to wallet permissions
Wallet Connection - Required for full features
Migration Summary - Show which servers will be accessible
Main App Navigation
Bottom Navigation (5 tabs)
Home - Your communities, recent activity
Communities - Server list, discover new ones
Chat - Direct messages
Voice - Active voice channels, calls
Profile - Settings, wallet, AI manager
Home Screen Flow
Dashboard Layout
Wallet Status - Connected wallet, balance indicator
Recent Activity - Last messages, mentions, voice activity
Active Voice Channels - Currently active voice rooms
Quick Actions - Join voice, check governance, create channel
Notifications - Unread messages, mentions, votes
Actions Available
Tap notification → Navigate to relevant channel
Tap voice channel → Join voice room
Tap message → Go to text channel
Pull to refresh → Update all data
Communities Screen (Server List)
Main Sections
My Communities (top) - Joined servers with unread counts
Discover (bottom) - Public servers, invite links
Community Structure (Like Discord Server)
Server Name - Community identity
Text Channels - #general, #random, #announcements, etc.
Voice Channels - General voice, meeting rooms, etc.
Role-Based Channels - Admin-only, member-only, token-holder channels
Governance Channels - #proposals, #voting (when applicable)
Community Detail Screen
Server Header - Name, member count, online status
Channel List - Text and voice channels organized by categories
Member List - Online members, roles, permissions
Server Settings - Notifications, roles (if admin)
Channel System Flow
Text Channels
Channel List - Organized by categories (General, Governance, etc.)
Message History - Infinite scroll, like Discord
Message Input - Text, emoji, file attachments
Member List - Sidebar with online members
Thread Support - Reply threads for organized discussions
Voice Channels
Voice Channel List - Available voice rooms
Join Voice - One-tap to join voice chat
Voice Controls - Mute, deafen, screen share
Voice Settings - Push-to-talk, voice activation
Voice Permissions - Role-based speaking rights
Video Calls
Video Toggle - Camera on/off in voice channels
Screen Share - Share screen with channel members
Video Settings - Camera selection, quality settings
Picture-in-Picture - Minimize video while using app
Role-Based Access System
Role Management
Server Roles - Admin, Moderator, Member, Token Holder, etc.
Channel Permissions - Read, write, voice, video per role
Token-Gated Roles - Automatic roles based on wallet holdings
Custom Roles - Server-specific role creation
Permission Examples
Public Channels - Everyone can read/write
Member-Only - Requires community membership
Token-Holder - Requires specific token in wallet
Admin-Only - Server administrators only
Governance - Voting-eligible members only
Governance Integration
Governance Channels
#proposals - Create and discuss proposals
#voting - Active votes, results
#announcements - Governance updates
Voting in Channels
Proposal Messages - Governance posts appear in channels
Quick Vote - Vote directly from channel message
Vote Threads - Discussion under proposal messages
Results Display - Real-time vote counts in channel

Community Customization
Channel Backgrounds - Community hosts can set custom chat backgrounds for each channel
- Upload custom background images for different channels
- Set opacity and overlay effects for readability
- Preview background changes before applying
- Background library with preset themes and patterns
- Seasonal/event-specific background collections
- User preference to override community backgrounds
Server Themes - Color schemes and branding customization
Custom Emojis - Upload community-specific emojis and stickers
Sound Effects - Custom notification sounds for communities
Welcome Messages - Customizable onboarding experience for new members
Channel Customization - Per-channel color schemes and visual themes

This is Discord but with wallet-based identity and governance features built in. No trending topics, just communities with channels, voice, and governance when needed.
